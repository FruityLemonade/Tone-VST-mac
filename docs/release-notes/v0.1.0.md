## Installation
1. Unten `XTONE-win64.zip` herunterladen und entpacken.
2. Den Ordner `XTONE.vst3` nach `C:\Program Files\Common Files\VST3\` kopieren.
3. FL Studio → *Options → Manage plugins → Find installed plugins* → XTONE im Channel Rack hinzufügen.

## Was schon geht
- Eigene Retrigger-Uhr: Rate-Quelle **BPM** (1–60.000 BPM + Teiler inkl. Triole/punktiert), **Hz** oder **Host ×** (Projekttempo × 1…128, Phasenlock).
- **Pitch-Modus Relativ** (Default): Grundnote C5 (FL) spielt genau das Tempo, jede Oktave höher verdoppelt die Rate. **Absolut**: A4 = 440 Hz.
- Sub-Sample-genaue Retrigger, Cut + Declick, Gate, Sample-Pitch, Pitch-Env, Glide, Pitchbend, Sustain, Note-ADSR.
- Sample laden per [Laden…] oder Drag & Drop (WAV/AIFF/FLAC/OGG/MP3), Einbettung ins Projekt bis 32 MB, [Normalisieren].
- Slices: Doppelklick = Marker, Ziehen = verschieben, Rechtsklick = löschen, [Gleichmäßig]. MIDI-Modus **Slice**.
- Schon drin, obwohl erst später geplant: Oversampling 1x–8x, Drive + Soft/Hard-Clip, Mono, Jitter, Tune-Snap, Overlap, Unison.
- Live-Anzeige: Rate, BPM-Äquivalent, Ton (wissenschaftlich + FL), Slice.
- Presets: Init, **Speed Grid 500** (Referenz-Charakter), Melodic A440.

Noch ohne Wirkung (Regler schon sichtbar): **A/B, Rampe, LFO 1/2, Sequencer**.
